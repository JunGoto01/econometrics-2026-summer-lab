SLIDE 10｜fixestの式

            
縦棒の左側に説明変数、右側に固定効果を指定する

            

              feols(income_index ~ anime_stage:post | municipality_id + year)
              
結果income_index

              
DiDanime_stage:post

              
固定効果municipality_id + year

            

            
    
              
  • :は二つの変数の積。「舞台自治体で、かつ放送後」を表す。
    • 
              
  • |は通常の説明変数と固定効果を分ける。因果の矢印ではない。
    • 
              
  • cluster = ~municipality_idは、同じ自治体の年ごとの誤差が似る可能性を考慮する。
    • 
            

            
固定効果のみでは、時間とともに変化する交絡要因や平行トレンド仮定の違反には対処できない。

# 0. dataを確認
dim(data)
head(data)
table(data$unit_id)

# 1. 群×時点の平均を図示
trend <- aggregate(outcome ~ treated + time, data, mean)

# 2. 二方向固定効果で平均的なDiDを推定
did_model <- fixest::feols(
  outcome ~ treated:post | unit_id + time,
  data = data,
  cluster = ~unit_id
)

# 3. イベントスタディ
event_model <- fixest::feols(
  outcome ~ i(relative_time, treated, ref = -1) |
    unit_id + time,
  data = data,
  cluster = ~unit_id
)
fixest::iplot(event_model)

似ているからではなく、反実仮想の動きを再現できる理由を語る。

            
MODEL固定効果の役割を説明したか
単位固有の水準差と共通時間変化を調整する。

            
CHECK0が出るべき場所を見たか

INTERPRET係数の単位を述べたか

LIMIT残る仮定を明記したか
