SLIDE 10｜fixestの式

            
縦棒の左側に説明変数、右側に固定効果を指定する

            

              feols(income_index ~ anime_stage:post | municipality_id + year)
              
結果income_index

              
DiDanime_stage:post

              
固定効果municipality_id + year

            

            
    
              
  • :は二つの変数の積。「舞台自治体で、かつ放送後」を表す。
    • 
              
  • |は通常の説明変数と固定効果を分ける。因果の矢印ではない。
    • 
              
  • cluster = ~municipality_idは、同じ自治体の年ごとの誤差が似る可能性を考慮する。
    • 
            

            
固定効果のみでは、時間とともに変化する交絡要因や平行トレンド仮定の違反には対処できない。

          


          

            
SLIDE 11｜固定効果に吸収される変数

            
固定効果のダミー列と同じ動きをする変数は、別の係数を推定できない

            

              

                
変数データ内の動きどのダミーで再現できるか回帰での扱い

SLIDE 25｜二種類の反証テスト

            
波及検証と負の対照アウトカムは、異なる問題を調べる

            

              
SPILLOVER｜P06隣接街区への犯罪移転
隣で自動車盗が増えれば、犯罪が消えずに場所だけ移った可能性がある。これは実在しうる波及経路の検証であり、純粋なplaceboではない。
調べる係数：adjacent_block:post

              
NEGATIVE CONTROL｜P07因果経路のない結果
水道漏水報告にも効果が推定される場合、施設街区固有の別の変化を警官配置の効果と誤認している可能性がある。
結果をwater_leak_reportsへ変更

            

            
「何を偽にするか」「処置から結果への因果経路がなぜないか」「効果が出たら何を疑うか」を推定前に定める。

          


          

            
セル P06
隣接街区への犯罪移転を波及検証で調べる

            
施設街区を除き、隣接街区を処置群として同じDiDを行う。これは「起きないはずの偽処置」ではない。警官配置で自動車盗の場所が隣へ移るという実際の因果経路を調べる波及検証である。

            
検証する仮定施設街区の処置が周辺へ波及しない
期待する結果犯罪移転がなければ0付近
0より大きい場合減少ではなく隣接街区への移転を疑う

            

              
              
              
              

              
SPILLOVER CHECK

            

          


          

            
セル P07
偽のアウトカムでも効果が出ないか調べる

            
同じ式の結果だけを水道漏水報告へ変える。警官配置から水道管の漏水発生への因果経路は想定しにくいため、これは負の対照アウトカムとして機能する。

            
偽にするもの結果を水道漏水報告へ変更
なぜ0を期待するか警官配置が漏水を変える経路がない
効果が出た場合施設街区固有の同時変化やmodelの誤指定を疑う

# 0. dataを確認
dim(data)
head(data)
table(data$unit_id)

# 1. 処置開始時点から分析用変数を作る
data$post <- as.integer(data$time >= treatment_start)
data$relative_time <- data$time - treatment_start

# 2. 群×時点の平均を図示
trend <- aggregate(outcome ~ treated + time, data, mean)

# 3. 二方向固定効果で平均的なDiDを推定
did_model <- fixest::feols(
  outcome ~ treated:post | unit_id + time,
  data = data,
  cluster = ~unit_id
)

# 4. イベントスタディ
event_model <- fixest::feols(
  outcome ~ i(relative_time, treated, ref = -1) |
    unit_id + time,
  data = data,
  cluster = ~unit_id
)
fixest::iplot(event_model)
